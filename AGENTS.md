# Обязательные правила работы с прототипом

1. Исходный дизайн `axioma_pr.tsx` является утвержденным источником интерфейса.
2. Нельзя менять композицию, визуальный стиль, тексты, элементы управления или состав функций без прямого указания пользователя.
3. Подключение backend выполняется внутри существующего интерфейса. Нельзя заменять готовый экран упрощенным техническим UI.
4. Нельзя удалять или переосмысливать функцию только потому, что backend для нее еще не готов. Такой элемент остается в исходном виде и в подвешенном состоянии до отдельного решения пользователя.
5. Нельзя добавлять новую функцию, настройку, статус или пояснение без прямого указания пользователя.
6. Исправление ошибки должно сохранять исходный вид и пользовательский сценарий, если пользователь отдельно не попросил изменить дизайн.
7. Перед завершением любой UI-задачи нужно сравнить результат с исходным экраном и проверить его в браузере на desktop и mobile.

Эти правила имеют приоритет для всех изменений интерфейса в этом репозитории.
