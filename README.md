# Аксиома

React/Vite-прототип платформы для размещения PR-материалов на медиаплощадках.

## Как открыть

```bash
pnpm run dev
```

После запуска откройте:

```text
http://127.0.0.1:5173/
```

## Что входит в прототип

- лендинг «Аксиома»;
- регистрация и вход;
- кабинет заказчика;
- кабинет площадки;
- админ-панель;
- материалы, рекламодатели, каталог площадок, заказы, финансы, отчеты и настройки;
- моковые состояния заказов, публикаций, споров и выплат.

## Проверки

```bash
pnpm exec tsc --noEmit
pnpm run build
```
