# Аксиома

> Обязательное требование: исходный дизайн и состав функций прототипа нельзя
> менять без прямого указания пользователя. Подробности: [docs/DESIGN-GUARDRAILS.md](docs/DESIGN-GUARDRAILS.md).

React/Vite-прототип платформы для размещения PR-материалов на медиаплощадках.

Текущий порядок доработок: [docs/IMPLEMENTATION-PLAN.md](docs/IMPLEMENTATION-PLAN.md).

API подключается к исходному интерфейсу на `/`, без отдельного упрощенного кабинета.
Интеграция еще не завершена для всех разделов. Инструкции запуска, API и блокеры
публичного запуска: [docs/BACKEND.md](docs/BACKEND.md).

Утвержденная архитектура раздела репутационного мониторинга:
[docs/REPUTATION-ARCHITECTURE.md](docs/REPUTATION-ARCHITECTURE.md).

## Как открыть

```bash
pnpm install --frozen-lockfile
pnpm run api:local
```

В другом терминале:

```bash
pnpm run dev
```

После запуска откройте:

```text
http://127.0.0.1:5173/
```

## Что входит в прототип

- лендинг «Аксиома»;
- регистрация и вход;
- кабинет заказчика;
- кабинет площадки;
- админ-панель;
- материалы, рекламодатели, каталог площадок, заказы, финансы, отчеты и настройки;
- сохранение материалов и вложений, проекты, рекламодатели, каталог и основной цикл заказов через API;
- часть административных, финансовых и вспомогательных экранов пока остается прототипом.

Для production задайте `INTEGRATION_SECRETS_KEY` (не менее 16 символов): он
используется сервером для шифрования ключей API-интеграций, включая DaData.
Ключ DaData можно сохранить в админке в разделе «API интеграции»; без него
подсказки адресов недоступны, а новые рекламодатели остаются на проверке.
